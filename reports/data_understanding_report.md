# Stage 1: Data Understanding & Inspection Report

## 1. Dataset Overview
- **Dataset File**: `dataset/Telco_customer_churn.csv.xlsx`
- **Total Rows**: 7,043
- **Total Columns**: 33
- **Duplicate Records**: 0
- **Unique Customers**: 7,043

## 2. Target Variable Analysis
- **Primary Target Variable**: `Churn Value` (Integer 0 or 1)
- **Associated Column**: `Churn Label` ('Yes' or 'No')
- **Class 0 (Retained)**: 5,174 (73.46%)
- **Class 1 (Churned)**: 1,869 (26.54%)
- **Imbalance Ratio**: 2.77:1 (Moderate class imbalance to handle during training)

## 3. Data Leakage & Column Exclusions
| Column Name | Type | Reason for Exclusion / Action |
|-------------|------|-------------------------------|
| `Churn Reason` | Leakage | Recorded post-churn; null for 100% of non-churned customers |
| `Churn Score` | Leakage | Pre-existing predictive churn risk score generated by IBM SPSS |
| `Churn Label` | Redundant Target | String duplicate of `Churn Value` |
| `CustomerID` | Identifier | Arbitrary identifier; would cause spurious memorization |
| `Count` | Constant | Constant value (= 1) across all records |
| `Country` | Constant | Constant value ('United States') across all records |
| `State` | Constant | Constant value ('California') across all records |
| `City`, `Zip Code`, `Lat Long`, `Latitude`, `Longitude` | Geographic / High Cardinality | Spatial attributes with near-zero linear correlation (<0.005) to churn |

## 4. Modeling Feature Specification
### Numerical Features (4)
- `Tenure Months`: Length of customer relationship in months (0 to 72)
- `Monthly Charges`: Current monthly bill amount in USD ($18.25 to $118.75)
- `Total Charges`: Cumulative billed amount (11 missing values imputed with 0.0 for new customers with tenure=0)
- `CLTV`: Customer Lifetime Value score ($2,003 to $6,500)

### Categorical Features (16)
- **Demographics (4)**: `Gender`, `Senior Citizen`, `Partner`, `Dependents`
- **Phone Services (2)**: `Phone Service`, `Multiple Lines`
- **Internet & Add-on Services (7)**: `Internet Service`, `Online Security`, `Online Backup`, `Device Protection`, `Tech Support`, `Streaming TV`, `Streaming Movies`
- **Account & Contract Terms (3)**: `Contract`, `Paperless Billing`, `Payment Method`
